# Books

Печатные материалы для пациентов.

## Рекомендованная литература

Откройте [`https://dockavetski.github.io/Books/pages/`](https://dockavetski.github.io/Books/pages/).

Для практики:
- меню разделов слева
- поиск по автору/названию
- выбор разделов или отдельных книг
- **Печать выбранного** или печать одного раздела
- копирование ссылки на раздел (`#s5` и т.п.)
